Model Information & Technical Architecture

Primary Model Architecture: Support Vector Machine (RBF Kernel, C=10.0, Balanced Class Weights)

Feature Engineering: 32x32 Bilinear Grayscale Downsampling (1,024 Normalized Pixel Features)

Held-Out Test Accuracy: 99.2188% (1,270 / 1,280 correct predictions)

Macro F1 Score: 99.4325% | Weighted F1 Score: 99.2185%

Training Dataset: 6,400 MRI Slices across 4 Classes (Kaggle Alzheimer MRI Dataset)

Validation Split: Deterministic 80/20 Stratified Split with Hash Audit Verification

Explainability Algorithm: Spatial Occlusion Sensitivity Feature Attribution (4x4 Patch Masking)

How It Works & Pipeline Guide

  1. Image Ingestion & Preprocessing: The uploaded MRI image is converted to a 1-channel grayscale representation and downsampled to 32x32 pixels.
  2. Feature Flattening: The 32x32 grid is flattened into a 1,024 numeric feature vector normalized between 0.0 and 1.0.
  3. StandardScaler Standardization: Features are standardized using training pixel mean and standard deviation.
  4. RBF-SVM Classification: RBF kernel support vector machine calculates decision boundaries across the 4 class projections.
  5. Occlusion Explainability Heatmap: A 4x4 masking block slides across the image to identify key regions driving the prediction.

About Alzheimer's MRI Classifier

This application is an educational machine learning workstation built to demonstrate classical machine learning (RBF Support Vector Machines) applied to standardized brain MRI slice classification.

It compares 4 cognitive stages: Non Demented, Very Mild Demented, Mild Demented, and Moderate Demented.

How to Interpret Predictions & Confidence

Predicted Stage: The class that received the highest decision score from the RBF-SVM model.

Confidence Percentage: Softmax-normalized probability over decision scores. Higher values reflect greater similarity to training patterns of that specific stage.

Heatmap Overlay: Green/yellow highlighted regions show spatial locations where pixel intensities strongly impacted the decision score.
